## 0. TL;DR

51 条锥内债（50 `nli*` + 1 hLP）在数学上是**同一类问题的 51 个实例**：6 维盒上
「有理函数 + √ + arctan（atn2）」表达式的带余量 positivity（余量 1e-5～1e-2，
盒宽 0.4–0.65）。当前三条路线（bb_arb/TM 证书农场、角点表、逐件解析）各自卡在
三个**独立的成本旋钮**上，其中两个（农场、几十万行生成码）不是数学难，是
**载体与落地形态选错了**。

核心主张：**仓库已经三次独立发明了同一个数学思想**（§2），要做的是把它收敛为
一个通用引擎（代数化 + Bernstein 载体 + 数据落地，§3–§5），把「50 个 bespoke
战役 + 27,000 CPU·h 农场」换成「一次性 ~1–2k 行人审数学 + 每债一张数据表」。
LP/hLP 侧另有一个风险更低、收益可能更大的 dual 证书 checker 杠杆（§6）。
先花 1–3 车道日做零解冻纯 Python 侦察即可判定真伪（§9）。

## 2. 核心观察：同一思想已被本仓库独立发明三次

1. **`nliRestQITNPEA4003532128a`**（`06285994`，`lean/Kepler/Text/NliQitnpea.lean`，
   142 行，零证书）：√2 两侧钉死降维 → 变量替换 `u=8−x1, t=x2+x6−x1` →
   对 t 凹 ⇒ 只查顶点 → 弦线盖凸曲线。**纯代数化消灭了全部数值**。
2. **`ztg_atn2_ge`**（`f47d472f`，`lean/Kepler/Text/ZTGDihKit.lean`）：
   `s·|y| ≤ x ⇒ atn2 x y ≥ arctan s − π/2`——**角度下界完全化归多项式不等式，
   无三角常数**，配两条有理 arctan 下界（`arctan(8/5) ≥ 1.008` 等）。
3. **`NliBanksZTGIJCF4Dih`**（`decbc61c`，129 处 Bernstein 命中）与
   `NliBanks6`（`gckbP = P(end) + d·Q(d)`）：quartic 取一个端点值 + **残差
   cubic 的 Bernstein 控制点全正**——Bernstein 证书已在用，只是当**单变量
   小技巧**用。

这三件事是同一个大思想的碎片：**先代数化消掉超越项，再在盒上用
「多项式的组合证书」收口**。当前的问题是每个债家族把这个思想重新序列化
一遍成几万行 bespoke 代码——QITNPEA 是它、Kit A 是它、S2b 角点链也是它。
**第 51 次重造不会比前 50 次便宜。**

## 3. 杠杆 A：代数化——atan/sqrt 出场的位置比想象的浅

- **导数层面 atan-free**：任何 arctan 项的一阶导数是有理式
  （`d arctan(u) = u'/(1+u²)`；atn2 同款）。所以单调性/凹性证书根本不碰
  atan——全是代数函数的符号问题（`Gamma4Deriv1–8` 闭式已落库 `c05928f5c`，
  是这个方向的一半资产）。
- **值层面 atan 有界化**：arctan 单调、Lipschitz-1、变化平缓，用**有理
  Padé/Taylor 界**逐项夹（MetiTarski 的标准武器；仓内 `atan1_box`、
  `ztg_atn2_*` 已是同款）。
- **单根式精确消去**：`f = A + B√Δ`（Δ > 0）时
  `f > 0 ⟺ (A≥0 ∧ B≥0) ∨ (A>0 ∧ B<0 ∧ A²>B²Δ) ∨ (A<0 ∧ B>0 ∧ B²Δ>A²)`
  ——纯多项式条件，**零 wrap、零相关性损失**。多根式精确消去会爆炸，
  退到杠杆 B 的 Bernstein-form 运算，每个 √ 节点只付一次 O(h²)。

直接后果：**大量叶从 TM 档（27–31 s/叶）降为 poly 档（~1 s/叶）**——
这两个数字都在现行成本模型里，不需要新假设。

## 4. 杠杆 B：Bernstein 形式作为统一载体

多项式 p 在盒上的 Bernstein 系数向量 `c_β` 一个数据结构同时给出
HOL 引擎（`formal_ineqs`）赖以高效的三大杠杆：

| HOL 引擎杠杆 | Bernstein 对应物 | 成本 |
|---|---|---|
| 值包络 | `min c_β ≤ p ≤ max c_β`（基非负 + 单位分解） | 读系数 |
| 局部导数符号剪枝（`mono_depth=200`，把 10⁴–10⁵ 叶压到 10² 的关键） | ∂p/∂x_i 的 Bernstein 系数 = `c_β` 的**逐项差分** | O(N) 免费算出 |
| 凸性 glue | 二阶差分同款 | O(N) |
| 自适应细分 | de Casteljau（纯有理、无舍入） | O(N·d) |

关键性质：**多项式部分零 wrap**——对比 TM 把相关性塞斜率区间、塞不下就
漏进误差项复利（Gate-0 NO-GO 的直接死因，ρ1≈24.7）；Bernstein 把相关性
直接长在基里，收敛 O(h²) 且无复利。Gate-0 的判词（`12c81dee`，NO-GO）
按 FARM_PLAN §7.3 自己的口径是「贵 4×，但可跑」——换载体就是把这 4×
也吃掉，而不是复活死马。

Lean 侧一次性数学（人审资产，估 ~1–2k 行）：基非负、单位分解、区间包含、
差分导数引理、de Casteljau 细分、PosTree 式覆盖树。全部是初等归纳，
Mathlib 友好；对照 50 债 × 1–4 万行生成码。

## 5. 杠杆 C：引擎 + 数据的落地形态

Soundness 证**一次**；每债落地 = 叶表/角点表**数据**（有理数字面量）+
每叶一行 `decide`（内核重放检查，不重新发明证明）。内核零 `native_decide`、
零新公理——与 585 信任基座零接触，满足 AGENTS §2 全部禁造边。

两个直接推论：

1. **代码质量面变化**：数据可机器审计、无证明结构——§7.1-32 类
   「生成器正则补丁截断供给行」的 bug 在纯数据落地里结构性消失
   （生成器只产数据，不产证明逻辑）。
2. **一批「BLOCKED/不可写」判词其实是落地成本判词，会被直接溶解**。
   最典型是 `sqrt8`：FARM_PLAN §2.2 写「要压到余量以下需每坐标切 5–8 段 ⇒
   125–512 cells，**Lean 逐 cell 不可写**」——被判死刑的是「分项矩形」
   路线（结构性：a-矩形损失 = 余量 8×，这个数学结论不变），被判
   「不可写」的是**落地方式**；125–512 行数据在引擎+数据架构下是小时级
   的事。同型判词值得逐条重审。

## 6. LP / hLP：dual 证书 checker——同一种病的极端案例，药方更标准

> 这是全提案里**风险最低**的一件（数学是本科线性规划），单项收益却可能最大
> （一条 0.83 TB 硬墙 + 一个农场批次消失）。

### 6.1 现状（`lp-pilot-w1` 定标，DOC）

- 债面：hLP 本体 = 43,078 条 LP 终端记录，其中 **189/189 infeasible 已真证
  落库**（`lean/Kepler/Text/LP/LPLeafInfeas00.lean` + 189 个 `Kepler.LP.T*`
  **Farkas 模块**）；**待证 = 42,889 条 bound 叶**。清单债 `nliLpIneqs`
  （127 ids）与 `nliKcblrqcIneqDef`（4 合取，其中 **#2 num-contradiction
  无 LP 依赖、可先单独 MATH 收**）挂同账。
- 落地成本：**~66 s/叶内核、olean 16–21 MB/叶**；批 20 叶内存上限
  19.3 GB；全量磁盘 **0.70–0.95 TB（中心 0.83）**；pilot 折算全量
  794.8 CPU·h（生成 120.6 + 编译/内核 674.2）。
- 原版对照：HOL `Verify_all` 15+ h 农场（FARM_PLAN §6-④，信任类别对等）。

### 6.2 观察

66 s/叶 + 16–21 MB olean 说明当前落地每叶携带**重型证明文本**——这与
nli 侧 S2b 角点链是同一种病（每叶重新证明一遍本可一次证明的东西）。
而 LP 界的数学结构是三类债里**最标准**的：每个 bound 叶本质是
「LP 最优值 ≥ v」这类线性规划界断言。

**待审计假设**：若实测发现 66 s/叶主要来自证书规模（而非证明文本），
本节收益按比例缩水；审计是纸面半小时级（看一个 LPLeaf 模块的证明体
构成），应先行。

### 6.3 药方：LP 弱对偶证书

- **数学内核**（按债侧实际 LP 形式镜像调整；以标准形示意）：对
  `min cᵀx s.t. Ax ≥ b, x ≥ 0`，任何**对偶可行** `y ≥ 0, Aᵀy ≤ c` 给出
  `min ≥ bᵀy`。证明 = `cᵀx ≥ (Aᵀy)ᵀx = yᵀ(Ax) ≥ yᵀb` 三步 `calc`
  （Finset.sum 搬运 + 非负性），Lean 侧**一次性 ~100–500 行**。
- **每叶数据** = 对偶向量 y（精确有理）+ 界 v；内核检查 =
  `y ≥ 0 ∧ Aᵀy ≤ c ∧ bᵀy ≥ v` 的矩阵-向量有理算术，`by decide` 收——
  与已落库的 189 条 Farkas 模块**完全同款的「证书-检查」模式**，
  仓库已有 189 个先例，不是新发明。
- **离线侧**：单纯形/内点数值解 + 有理重构 + 精确验证。验证永远便宜
  （多项式个有理比较），求解器永不进信任面。
- **规模估算（EST）**：y 是 KB 级数据 ⇒ 源/olean 从 16–21 MB/叶 →
  KB–数十 KB/叶，总池 ~GB 级（**0.83 TB → 下降两到三个数量级**）；
  内核从 66 s/叶 → **秒级**（若 6.2 假设成立）。42,889 叶 × 1–5 s ≈
  **12–60 CPU·h 内核** + 生成——单 lean 数天到两周可收，
  **不需要 1.2 TB 外置盘、不需要农场并发**。FARM_PLAN 解冻项 ⑤
  （磁盘）可能整个变成不必要，F4 从农场批降级为本机批。

### 6.4 边界与通道

1. 先做 §6.2 的审计（纸面，半小时级）确认「文本驱动」假设。
2. 新增 checker/certificate def 属 **LP/D 证书层**——在用户 hold 名单上：
   需显式解冻，或与解冻请求 ④ 合并裁决（「批准 ④ 时以 dual-cert 形态
   执行」）；如涉既有 def 改动走 DEF-FIX 章程。
3. 陈述逐字不动，纯证明内部改造，无 SF 通道需求。
4. `Kcblrqc #2` 与引擎无关，可先行单独收（MATH）。

## 7. parity 论证：为什么这不比原版「更差」，反而是补课

- **HOL 原版走的本来就是 engine + data**：`formal_ineqs` 引擎（二阶 Taylor +
  逐子盒局部导数符号剪枝 + 凸性对接 + 自适应搜索）产出 **32–139 叶/盒**、
  ZTGIJCF4 全 16 条 76.0 CPU·h / ox3q1h 230 条 757.3 CPU·h（azure 实测，
  DOC）；然后 23,242 条 digest 经 **deserialization 公理**导入
  （`serialization.hl:612/623`，`g4hol-w1` 考古）。公理导入被 AGENTS §2
  正确禁掉，但「引擎+数据」这个**架构**正是原版便宜两个数量级的原因。
  我们用内核 `decide` 重放数据 = 同架构、**更小信任面**——不是 extravagance，
  是补上原版有、被我们正确禁掉的那一半的合法替代品。
- **我们与 HOL 的叶数差（10⁵ vs 10²）就是载体锐度差**：同一批债，bb_arb/TM
  ρ1≈24.7，HOL 引擎 32–139 叶。Bernstein 载体 + 差分剪枝就是 HOL 三杠杆的
  直接对应物（§4 表），且检查更便宜。
- **文献背书**：
  - Akbarpour–Paulson **MetiTarski**（JAR 2010）：「特殊函数有理逼近替换 +
    实闭域决策」自动证明 Flyspeck 非线性不等式的大子集——杠杆 A 的先例。
  - Solovyev–Harrison（arXiv:1301.1702）：Taylor 区间方法 = 现行 bb_arb/TM
    路线的原版——杠杆 B 是它的载体升级而非发明新数学。
- 终局口径（AGENTS §1「不比 Flyspeck/Isabelle 更差」）在此方向下**更容易
  达成**：内核重放 < digest 公理导入的信任面。

## 8. 诚实边界（先说不行的）

1. **不是魔法**：余量是真实的，数值/数据不会消失。每债仍可能落下几百到
   几千行有理数据表。但数据 ≠ 证明文本：可机器审计、无证明结构、
   生成器 bug 面结构性缩小。用户对「几十万行证明代码」的反对针对的是后者。
2. **叶数下降倍数是待测命题，不是承诺**：多根式债精确消根会爆炸
   （退 Bernstein-form DAG 运算，每个 √ 节点付一次 O(h²)）；ox3q1h 的
   19 个 dihY 项求值关联损失仍需实测；recost 自己就有低估 2–3 个数量级的
   前科（IXPOTPA）——对一切 EST 保持谦卑，这正是侦察车道存在的理由。
3. **内核 decide 成本未定**：Bernstein 系数核验在 degree ~(6,…,6)⁶ 全基上
   可能不便宜；「系数作为数据 witness 给出、内核只验恒等」vs「内核自算
   转换」两条设计都待 pilot 实测。
4. **IXPOTPA**（自相似无限阶梯，10 配置全 TRUNC）不在本杠杆覆盖内，
   维持 BLOCKED。
5. **sqrt8** 的结构不可能性结论（分项矩形损失 = 余量 8×）不变；杠杆 C
   可能解锁的是「125–512 cells 不可写」那半个判词，需重审而非承诺。
6. **hLP 的 §6 收益以审计假设成立为前提**（§6.2/§6.4-1）。
7. **逐债的「真数学宝石」仍然值得先找**（QITNPEA 式降维、`ztg_atn2_ge`
   式归约）——引擎是地板不是天花板；nli-campaign §7-1「先数学后证书」
   原则不变，引擎只是把「证书」这半边的成本曲线压平。

## 12. 成本反差框架 + 剪枝 kit 机会（2026-11-20 追加，普查在飞）
