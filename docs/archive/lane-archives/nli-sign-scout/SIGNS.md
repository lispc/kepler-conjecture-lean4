# SIGNS — `nli-sign-scout`：28 条银行切片六偏导的认证符号侦察

日期 2026-11-06；主仓 HEAD `86ffb9c7`；**主仓 tracked/staged 零改动**，全部产物在本快照
目录。对象 = 工作单 §1 的 28 条（B1 14 + B2 14），切片逐字取自
`lean/Kepler/Text/PackingAuto21.lean`（`bank_*` 定义，2026-11-06）。

## 0. 一句话结论

**M = 0 / P = 28 / N = 0。** 28 条每一条都至少有一个轴在**单片内**被认证变号
（rigorous witness pair，逐条用直接值函数的有限差分复核过，差 ≤1e−7），
所以**最小值不被逼到顶点**，这条"六偏导全定号 ⇒ 单顶点求值"的捷径
**一条也闭不了**。包括看起来最接近 M 的三条（只有 1 个变号轴）——它们的
唯一变号轴的零面横在 `(y_k, y_other)` 平面上（witness 由 y6/y5 分开），
且沿该轴在折点面 `y = 2.52` 上还有局部极小，仍然不是顶点。

## 1. 方法（S1 + S2）

### 1.1 切片真形式（含 `dihY` 项与常数）

统一记 `g4 = gamma4fgcy y lmfun`，`A = 2·mm1/π`，`B = 8·mm2/π`。把 Lean 的
`vol4f = A·(4 个 solY) − B·(6 个 lmfun·dihY)` 展开并用 `4πA = 8·mm1` 消去 π：

```
g4 = volY + 8·mm1 − A·Σ₁₂ dihY + B·Σ₆ lmfun(yᵢ/2)·dihYᵢ
gamma3f(y1,y2,y6,√2) = vol3r + 6·mm1 − A·Σ₉ dihY + B·Σ₃ lmfun·dihY
```

### 1.2 模型与导数（无超越函数的导数）

- `dihY y = π/2 + atn2(√(4x₁Δ), −Δ₄)`，`xᵢ = yᵢ²`。在 `yᵢ>0, Δ>0` 上用
  `√(4x₁Δ) = 2y₁√Δ`。
- `atan2` 的导数是经典的 `(x·v′ − y·u′)/(u²+v²)`（与 Lean `atn2` 的三个分支
  一致，在 `|V|=U`、(V,U)≠(0,0) 处 C¹）；因此 **一阶导表达式是 Δ、Δ₄
  及其偏导的有理式再乘 √Δ，完全不含 atan**。
- 复合 `lmfun(yᵢ/2)` 在折点 `yᵢ = 2.52` 处切开：左片取
  `f=(2h0−yᵢ)/0.52, f′=−1/0.52`，右片取 `f=0, f′=0`；每片是一个盒。

**模型验证**（`scripts/verify_main.py`，全部通过）：

- 与逐字转写的 mpmath 镜像（`vol4f` 的四 solY + 六 lmfun·dihY 原式）比较：
  28 条 × 4 随机点，区间模型**全部包含**直接值（0 mismatch）；
- 一阶导与直接值函数的中心差分比较：9 条 × 2 点 × 6 轴，0 mismatch（<1e−6）；
- 紧凑导数公式与 sympy 符号求导在 2 个点上 12 位一致（`scripts/test_deriv.py`）。

### 1.3 认证常数（`scripts/certconst.py`）

| 常数 | 区间 | 来源 |
|---|---|---|
| π | `(3.14159265358979323846, …847)` | Lean `g4v_pi_bounds`（1e−20） |
| √2 / √8 | mpmath.iv 的定向舍入开方 | Lean `g4v_sqrt2/sqrt8_bounds` 复核 |
| mm1 | `[1.0120808, 1.0120809]` | Lean `g4v_mm1_bounds` |
| mm2 | `[0.02541450, 0.02541451]` | Lean `g4v_mm2_bounds` |
| A = 2mm1/π | `[0.6443106485, 0.6443107122]` | Lean `g4v_AB_bounds` |
| B = 8mm2/π | `[0.0647174928, 0.0647175183]` | Lean `g4v_AB_bounds` |
| h0 / hplus / aSpine5 / bSpine5 / betaBumpLb | 精确有理数 | 定义 |

**hminus**：Lean 只有 `1.2 ≤ hminus < 1.3`（`mi_hminus_prop`）与
`hminus < h0`（`mi_hminus_lt_h0`），没有数值夹逼。本车道自己认证：
`F(h) = marchalQuartic h − lmfun h` 在 `[1.2,1.26]` 上 `F′ > 0`（400 点
`F′` 下界 > 0），端点异号，用精确有理数二分到宽度 `9.7e−29`：

```
hminus ∈ [1.2317544220903031693…, 1.2317544220903031694…]
2·hminus = 2.4635088441806…
```

（与 `gamma4-w6` 汇报的 `2.4635088442` 一致。）所有 `2hminus` 盒子端点都用
该区间的外端，属保守加宽（宽度 1e−28，对判定无影响）。

### 1.4 符号判定的认证协议

1. **witness pair（认证 ±）**：在同一片内取两个点，用**点区间**（mpmath.iv，
   dps=40，定向舍入）算出严格 `>0` 与严格 `<0` 的区间 ⇒ 该片内变号。
   每条银行的该对点再用**直接值函数的有限差分**独立复核（`verify_witness.py`、
   前向差分表见 §3.2），全部一致。
2. **采样只用于找 witness**：在片内取 64 个角点 + 90 个随机内点；角点规则：
   折点 2.52 取精确值（该片的单侧导数），盒端点向内缩 1e−9（保证在真实银行盒内）。
3. **没有 witness 的轴**：不据此断言定号。`SIGNS.tsv` 里这些格子写 `+`/`−`
   仅表示 sampled-hint，**`certification` 列逐轴标注 `sampled-hint`**；
   另做了 2000 盒的分支定界部分证书（约 98.5% 盒定号、0 个反号盒、~30 盒未决），
   但它**不是**全域证书，未用于任何结论。
4. 所有判定脚本：`scripts/final_scan2.py`（witness 总表）+
   `scripts/verify_witness.py`（FD 复核）+ `scripts/test_deriv.py`（符号复核）。

## 4. 顶点值 / 现有值（S3 第二段）

**没有任何 M 档**，所以严格说没有"极小顶点"。仍把"朴素下顶点"的值算出来作
情报（`scripts/vertex_values.py`，区间与直接值 0 mismatch）：

- 26 条下顶点 main **为正**（最小 `FHBVYXZa`：`[9.708e−5, 9.898e−5]`；
  次小 `QITNPEA3848804089`：`2.88e−3`）。
- **2 条下顶点 main 为负**：`QITNPEA5400790175a` `[−1.4053e−3, −1.4043e−3]`、
  `FHBVYXZv2a` `[−5.6029e−3, −5.6010e−3]`。这两条**任何"顶点 + 求值"路线都不可能闭**
  ——顶点本身就落在不等式的反面。
- 上顶点全部很大（~2e−1 … 5.4e−1），符合"函数从下到上整体增大"。

**现有值（`gamma4-val1e6`）覆盖情况**：

- 已有 `(2h0,2⁵)`、`(2hplus,2⁵)`、`(√8,2⁵)` 三个 gamma4 角点。
- **28 条的 56 个下/上顶点没有一个等于这三个角点**（因为所有银行
  `y2 ∈ [2,2hmin]`，上顶点是 `2hmin` 而非 `2`；下顶点 y1 是 `2hmin`）。
  ⇒ 即使某条是 M，也**必须补一次新求值**，"现成值直接推"的条数 = **0**。
- **9 条**（`ZTGIJCF4_0_0_0_0` + 8 条 narrow-box B2）的下顶点恰好是
  `(2hmin,2⁵)`，即 `gamma4-val1e6` 的 V4 GAP（hminus 有理夹逼未做）。
- 其余 19 条的下顶点含 `2hmin` 与其它 `2hmin` 坐标，也需要新求值。

**需补的求值清单**（若以后仍想走顶点/剖分路线）：

1. `gamma4fgcy(2hminus,2,2,2,2,2)` 的认证区间（hminus 有理夹逼 + 该点的
   sqrt/atan 求值）——9 条 narrow-box 银行的下顶点，就是 V4 GAP；
2. 其余 19 条各自的下顶点（坐标都是 `{2, 2hminus, 2hplus, √8}` 的组合，
   需要逐点的 atan2/√ 区间表）；
3. 但注意 §3：这 28 条都**不是 M**，上述求值本身不会把任何一条闭掉。

## 5. 两条 gamma3f 银行的 junk 区（必须记住）

`QITNPEA5400790175b` 与 `FHBVYXZb` 的 `gamma3f y1 y2 y6 (√2)` 在盒上有
**约 6.9% 的体积（16/64 角点）`Δ₃ = deltaX(2,2,2,y1²,y2²,y6²) < 0`**
（最小 −16.4）。Lean 的 `Real.sqrt` 对负数是 0，所以那里 `vol3r` 与
`U=√(4x₁Δ₃)` 都是 junk 值（`vol3r=0`、`atn2(0,·)` 取 ±π/2 或 π），
**光滑模型不适用**。

本报告的处理：
- 轴 2/3/4（y3,y4,y5）上 `gamma3f` 恒等于 0（它只依赖 y1,y2,y6），导数不受影响；
- 轴 1/2/6（y1,y2,y6）的 witness 只在 `Δ₃ > 0` 的点上取（`core.dih_deriv_iv`
  对 `Δ₃` 做了正性断言，`Δ₃ ≤ 0` 的点被跳过），所以 §2 的 `±` 仍然有效；
- 但这两条的**任何全域值声明**（包括顶点值）都必须先处理 junk 分支，不能直接
  用光滑值。

## 6. 排期（S4）

- **M 档 0 条 ⇒ 本路线合计估 0 行**（60–150 行/条的口径下）。
- 若退而求其次做"剖分 + 每格顶点"：最粗的下界是每条 `2^k` 格

- 三条 k=1 的银行是唯一"看起来便宜"的：但变号轴在折点面取极小，

  仍需全域盒证书 ⇒ 每条约 150–300 行起，三条 ~500–900 行，仍然不划算。

## 7. 一句话给编排者

**"六偏导全定号 ⇒ 单顶点求值"这条路对 28 条一条也不成立**：不是"还没证"，
是每一条都有一个**认证的片内变号轴**（107 个变号轴），其中 3 条还卡在
折点面的局部极小；另有 2 条下顶点本身就是负的。**建议不要再在这条路上
投 Lean 行数**，除非目标是逐条的剖分证书（774+ 格，证书农场）。
