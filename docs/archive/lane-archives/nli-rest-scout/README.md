## B1 回执（2026-11-05，`nli-rest-b1`）：**0/14 闭合，但把原因钉死了**

本 README 上面的排期决定第 1 条（B1 模板批）已执行，结果 **DONE 0 / GAP 14，sorry 净 0**。
这不是"再努一把就行"，是三个各自独立的硬阻碍，全部有机器证据：

1. **`rad2 > 2` 支在 H-单调下全角点假**：`H_lower` 实测 `−11.77 … −187.77 < 0`
   ⇒ 这 14 条**不能**走 `H = rhoX − 8·deltaX` 的单调 kit，必须走 `gamma4fgcy` 支。
2. **`gamma4fgcy` 支余量只有 7.80e−4 … 3.70e−2，且含 `sqrt`/`atan`/`π`**
   ⇒ `norm_num` 不可判，模板的"有限情形 `norm_num`"这条路直接断了。
3. **逐片凹性数值上成立但库内无资产**：14 条二阶导全 ≤0（最弱 −3.81e−3），
   但 `Gamma4Deriv8` 只有一阶导、`Gamma4Feed` 只有窄盒 `[2,2.001]⁶`
   ⇒ 没有 gamma4 的二阶导/凹性件，凹性事实升格不成证明。

**kink 判决被证实是决定性的**：14 条里 **12 条**的 refined argmin 落在 `y = 2.52` 面上；
最薄的 `ZTGIJCF4_0_0_0_0` 从字面 64 角点 5.37e−3 缩到 refined **7.80e−4**（6.9×）。

## B2 回执（2026-11-05，`nli-rest-b2`）：**0/14，但把"为什么不可能"量化到了根上**

B2 走的是与 B1 完全不同的路线（宽盒**值包络**），同样 0 闭合，但发现了两件比进度更重要的事：

### 1. 字面宽盒里含**退化四面体** ⇒ 宽盒 D 包络根本不存在

银行盒字面是 `[2hmin,2hplus]×[2,√8]⁵`，角点 `(4,4,8,4,4,8)`（平方变量）上 `Δ = 0`、`A = 0`。
⇒ `D_s = 分子/Δ^?` 在该点发散，**任何"整盒 D 包络"的提法都是病态的**。
B2 改在平方盒 `[4,(2hplus)²]⁶ = [4,7.0267]⁶` 上工作，并明确：覆盖 7/14；
另 7 条的盒含 `x = 8` 槽，需另建 `B_k = [4,7.0267]⁵×[4,8]` 族（该族 `Δ ≥ 54.7107`，按四面体群传递），**未做**。

### 2. 包络路线在宽盒上定量不可行

- 宽盒包络比窄盒宽 **1.6e3 – 7e5 倍**（`D1 ∈ [−701,701]`、`D2..D6 ∈ [−0.893,0.404]` 跨零）。
- **WBL-1**：包络给导数的松弛 `(2·mm1/π)·12·2·y·1.297 = 53.2`，而真导数 ≤0.5 ⇒ **106×** ⇒ 定不出符号。
  这不是实现问题：`y₂/y₄` 上 `∂gamma4fgcy` 实测 `∈ [−0.034, +0.378]` **本身就是变号的**。
- **WBL-2**：角点值精度差 8–12 倍（需要 <1.3e−4，`Gamma4EnvNum` 只有 ~1e−3）。
