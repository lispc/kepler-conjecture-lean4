# `gamma4f` 在 sharp 盒上的数值证据（40 位精度，mpmath 复刻 Lean 定义）

> 目的：把 `nli-bank-triage` 判为 `NEEDS-MATH` 的两件（`RIBCYXUsharp` / `IYOUOBFsharpv2`）
> 从"死路"改判为"一条解析引理"。脚本 = 本目录 `mpmath-replication.py`（复刻
> `deltaX`/`deltaX4`/`atn2`/`dihXf`/`dihY`/`solY`/`volXf`/`volY`/`vol4f`/`lmfun`/`sol0`/`tau0`/`mm1`/`mm2`）。
> `mp.dps = 40`。

## 1. 两个角点都是精确 0

| 角点 | `gamma4f` 值 |
|---|---|
| `(2,2,2,2,2,2)` | **−2.3e−41**（40 位下即 0） |
| `(√8,2,2,2,2,2)` | **5.7e−41**（40 位下即 0；且 `lmfun(√8/2) = 0`，走 `h > h0` 分支） |

## 2. 逐变量递增（盒 `[2, 2.001]^6`）

| 配置 | `gamma4f` |
|---|---:|
| 全 2（角点） | 0 |
| 抬一个变量到 2.0001 | +8.25e−6 |
| 抬一个变量到 2.001 | +8.23e−5 |
| 抬三个变量到 2.001 | +2.47e−4 |
| 全抬到 2.001 | +4.96e−4 |

线性增长（δ=1e−4 → 8.2e−6；δ=1e−3 → 8.2e−5）⇒ 角点附近偏导 ≈ 0.082，余量充足。

## 3. 全域单调性抽样

8 个盒内点（6 随机 + 2 结构：交替端点 / 只抬最后一个）× 6 个变量，共 **48 次**
"把 `y_k` 从 2 抬到 2.001" 的差分：**零违反**。

⇒ 经验结论：`gamma4f` 在 `[2,2.001]^6` 上对每个变量单调递增，故
`min = gamma4f(角点) = 0`。

## 4. 由此推出的施工路线

1. **角点精确值**：`gamma4f 2…2 = 0` 归约为 `dihXf 4 4 4 4 4 4 = arccos(1/3)`（正四面体
   二面角）与 `volXf 4…4 = √8/3`；第二条再加 `lmfun(√2) = 0`。
2. **逐变量单调**：`∂gamma4f/∂y_k ≥ 0`（需 `volY = √(deltaX)/12` 与 `solY`/`dihY` 的单调性；
   本仓已有同型件 `p25w_dihXf_mono_x4`）。
3. 拼装 `gamma4f(y) ≥ gamma4f(角点) = 0`。

**范围说明**：本文件是**数值证据**，不是证明。抽样 48 点不能代替单调性的分析证明；
若车道在某个变量上发现单调性不成立，以车道机器证据为准。
