## 0. 一句话

`ox3q1hP25` 原来是 `def … : Prop := sorry`：它不是普通未证命题，而是
`sorryAx` 直接占据 **Prop 本身**。任何陈述里出现 `ox3q1hP25` 的定理，
无论证明体多干净，`#print axioms` 都会遍历陈述类型并带出 `sorryAx`
（编排者实测：`def badProp : Prop := sorry; theorem t1 (h : badProp) : True := trivial`
→ `'t1' depends on axioms: [sorryAx]`）。本修把体换成
`ineqdata3q1h.hl` 的 230 条 `mk_ineq` 项的合取，使陈述成为可读、可审计的
显式 Prop；230 条本身仍**未证**（证书农场用户已冻结，后续波次），
本修只定形陈述，不产生新证明。

## 3. 转写规则与交叉核对

### 3.1 机械转写（禁手抄）

`transcribe_ox3q1h.py` 只读 HL 源，按 `mk_irecord`/`mk_ineq` 的同一控制流
生成 230 项；脚本对 HL 形状做硬断言（46 record、11 field、lindata 14、
branch ∈ {0,1}、numerics 7），任何不符即退出。生成顺序 =
`merge_ineq.hl:78-92`：record 0..45 外循环，case 0..4 内循环。

逐项渲染规则（均为定义/算术等价，不改语义）：
- `Sphere.ineq [(lo,x,hi), …] body` 展开为
  `∀ …, lo ≤ x → x ≤ hi → … → body`（与 PA21 `bank_*` 同约定）。
- `pathL(a,b)=(a,(a+b)/2)`、`pathR(a,b)=((a+b)/2,b)` 按 branch bits
  顺序应用；端点保持 `h0/hplus/hminus` 符号（`hminus` 在 Lean 中是
  `Classical.epsilon`，**不是**定义上等于 2.52，故不得折成数字）。
- `dih_y` → `dihY`（SphereKit 的 verbatim 端口）；`pi` → `Real.pi`；
  `gamma4fgcy` → PA20 的 verbatim `gamma4fgcy`（本文件已 import PA20；
  本地 `gamma4fgcyP25` 同体，留给其自身消费方）。
- `beta_bump_force_y` 内联为 `bump (y1/2) - bump (y4/2)`（HOL :614 的体）。
- cases 1–4 的 `/ &1 + &0 * beta_bump_force_y` 按算术正规化省略
  （i=1 保留 `/2 + (bump…)`）。`&1 * X` → `X`、`&0 * X` → 省略。
- 十进制字面量逐字保留（包括 HL 源自带的浮点尾迹
  `#0.7251449999999999`、`#0.44131200000000004`；它们是源数据，不是
  转写误差）。
