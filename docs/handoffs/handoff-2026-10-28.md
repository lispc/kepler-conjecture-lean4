   `LANE_FILES="Kepler/<路径>" THM="<文件内声明>" lock_build nice -n 19 bash
   scripts/auto_gate.sh <lean/起路径> <THM>`；LANE_FILES **逗号分隔**、路径

   SF_ITEM=<n>`；proposals 条目须在 `## N.` 与首个 `###` 之间含 `(a) HOL`；
   工作树唯一改动 = 已应用 patch；patch 头禁时间戳。**多集合比较按 `+++ b/lean/$FILE`
   单文件节进行**（sffile-w1 实测）：两 item 共 patch 兼容，但多文件 patch 须以各文件为
   `$FILE` 各闸一次才全覆盖（LANE_FILES 其余文件仅放脏不比对）。
3. **手写补丁必须规范化**为应用后真实 `git diff`（删加对 vs 上下文行致
   多集合错位）；规范化程序 = apply → `git diff HEAD -- lean/` → checkout →
   覆盖归档 → apply --check。
